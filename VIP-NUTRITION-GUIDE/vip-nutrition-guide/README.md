# VVIP 식단 가이드

인스타 팔로우어용 식단 가이드 웹앱. 성별·나이·키·체중·활동량·목표(다이어트/유지/벌크업)를 입력하면
하루 칼로리, 탄단지(5:3:2) 그램, 3끼/4끼 한 끼 기준, 식사 요령을 보여주고
칼로리·탄단지를 피드(4:5)·스토리(9:16) 이미지로 저장할 수 있습니다.

## 배포 (Vercel)
1. `npm install`
2. `npm run build` → `dist/` (단일 index.html 약 170KB + og.png, 외부 CDN·서버 없음)
3. `npx vercel --prod` 또는 `dist` 폴더를 Vercel에 업로드
4. 배포 후 나온 주소를 인스타 프로필 링크(litt.ly)에 넣으면 저장 이미지의 "프로필 링크에서 나도 받아보기" 문구와 맞아요.

### 링크 미리보기 (카톡·DM·문자)
Vercel에서 빌드하면 배포 주소가 자동으로 들어가 링크 미리보기 이미지(`public/og.png`)가 붙습니다.
Vercel 밖에서 빌드할 때는 `SITE_URL=https://내주소 npm run build` 로 주소를 지정하세요.
카톡은 한 번 공유한 링크의 미리보기를 캐시하므로, 바뀌지 않으면 카카오 공유 디버거에서 초기화하세요.

## 수정 포인트
- 링크/문구/만든 사람 소개/이미지 하단 문구: `src/config.js`
- 칼로리·탄단지 공식, 식사 조언 문구: `src/calc.js`
- 결과 화면 구성·멘트: `src/App.jsx`
- 저장 이미지 디자인: `src/saveImage.js`
- 색상·스타일: `src/styles.css` 상단 `:root`
- 링크 미리보기 이미지: `public/og.png` (1200x630)
- 검증: `npm test`

## 계산 방식
- 기초대사량: Mifflin-St Jeor / 유지 칼로리 = 기초대사량 × 활동계수
- 다이어트 -15~20%, 벌크업 +10~15% (다이어트는 기초대사량·성별 하한 1,200/1,500kcal 이하로 내려가지 않음)
- 탄수화물 50% : 단백질 30% : 지방 20% (5:3:2, 칼로리 기준). 체중 대비 단백질이 너무 높거나 낮으면 안내 문구 표시
- 만 18세 미만은 계산 차단, 참고용 안내 문구 포함

## 글꼴
- ROAD TO IFBB PRO 문구는 Anton(OFL 라이선스)에서 해당 글자만 잘라 `src/fonts/anton-roadtopro.woff2`로 포함했어요. 다른 문구로 바꾸면 글자를 다시 잘라야 합니다.
